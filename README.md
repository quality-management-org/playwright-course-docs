# Tài liệu học viên

## Automation Testing từ Zero đến Hero · Playwright & TypeScript

{% hint style="info" %}
**Khóa học 15 buổi · 8 tuần · ~30 giờ thực hành** — dành cho manual tester chưa từng học TypeScript/Playwright. Tập trung thực hành trên project thật: học đến đâu, code đến đó.
{% endhint %}

Đây là tài liệu đọc dành cho học viên. Cách sử dụng:

* **Trước buổi học:** đọc lướt mục *Chuẩn bị* (nếu có) để cài đặt sẵn công cụ.
* **Sau buổi học:** đọc lại để ôn, làm theo từng bước khi thực hành ở nhà.
* **Khi gặp lỗi:** mỗi bài đều có mục *Lỗi thường gặp* — tra ở đó trước khi nhắn trainer.

Tài liệu được phát theo tiến độ lớp học. Chúc bạn học tốt! 🎭
